**项目名称：hesphoros.github.io (Linux 拟桌面交互式全栈博客系统)** | *个人开源项目*
**核心技术：Vue 2 / Vuex / TailwindCSS / Vuetify / 自动化 Markdown 渲染机制**
[在线演示](https://hesphoros.github.io/) | [GitHub 主页](https://github.com/hesphoros/hesphoros.github.io)

- **深层次 Web 模拟交互架构**：打破传统静态博客边界，基于 **Vue 2** 体系从零实现了一个全高仿的 Linux GUI 虚拟桌面化博客渲染系统。深度模拟操作系统窗体管理逻辑（包含了任务栏 Dock、虚拟文件管理器界面组件 `WindowBasic` 与桌面环境 `Desktop` 的视图嵌套）。
- **组件化工程与全局状态管理**：重度依赖 **Vuex** 构建“操作系统级”的全局状态流转树，用于精确控制应用前后台切换、全局窗口拖拽层级（z-index）计算与上下文对焦。运用自适应布局引擎 **TailwindCSS** 及 `Vuetify` 建立全响应式沉浸体验体系。
- **动态解析渲染与生态融合**：通过封装 `markdown-it-vue` 插件搭配 Axios，实现了对 GitHub 仓库静态 Markdown 文件的跨域异步获取与高度拟真样式渲染，极大简化了博客文章运维管理；此外借助 `vue-aplayer` 和 `oh-my-live2d` 构建出色的多媒体流表现与交互视效。
- **现代化 CI/CD 交付链路**：运用 Github Pages Actions 及自动化构建流水线打通源码至线上服务的热敏部署，并依靠本地工程化脚本实现对文章与资源的自动整合，全站遵循高度组件化思想完成代码切割解耦设计。
