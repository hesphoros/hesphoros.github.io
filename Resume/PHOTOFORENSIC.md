**项目名称：PhotoForensic (高性能图像元数据数字取证引擎)** | *个人开源项目*
**核心技术：C++17 / Exiv2 / 图像解析 / 空间地理编码转换 / 跨平台构建**
[GitHub 主页](https://github.com/hesphoros/PhotoForensic)

- **图像底层数据提取与逆向分析**：基于 **C++17** 构建轻量级数字图像取证分析工具。集成底层多媒体解析引擎（基于 `Exiv2` 动态库），实现对主流图像封装格式的深度渗透，毫秒级提取图片底层的全量 EXIF、IPTC 及 XMP 等隐写元数据。
- **空间地理坐标解析引擎**：针对图片内嵌的 GPS 私有标签进行定点逆向计算，实现对十进制（DD）与度分秒（DMS）地理空间坐标系的自动化解码与浮点转换，精确还原目标拍摄的空间物理位置轨迹。
- **设备溯源与参数还原底座**：解构并映射庞大的硬件参数与出厂特征字典。完整还原并分析包括相机/手机厂商（Maker）、型号识别、底层固件版本、曝光光圈、焦距及快门速度等几十项结构化设备原始指标，为数字安全取证提供有效的数据链条。
- **工程化抽象与高扩展能力**：通过现代 C++ 规范提供极简的高阶 API 抽象层。系统具备对海量被破坏/污染图像的容错跳过机制（Exception Handling），支持自定义标签的深度过滤，以及未来向跨语言（如 JSON/CSV）高速序列化输出的技术拓展空间。
