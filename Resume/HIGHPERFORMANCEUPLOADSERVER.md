**项目名称：高性能安全异步上传系统 (HighPerformanceUploadServer)** | *个人极客/架构项目*
**核心技术：C++20 / FlatBuffers / mTLS 1.3 双向认证 / 无锁持久化队列 (Lock-free Persist Queue) / OpenSSL / 异步并发**
[GitHub 主页](https://github.com/hesphoros/HighPerformanceUploadServer)

- **高性能零拷贝二进制通信**：舍弃传统 JSON/XML，全链路引入 **Google FlatBuffers**（多层数据校验机制）作为核心消息承载体。通过内存直接映射与零序列化/反序列化开销设计，极大降低了 CPU 周期占用，实现超高吞吐量的网关级海量包处理传输能力。
- **高可用抗过载与持久化机制**：针对弱网环境与极端高并发断连场景，独立研发防 OOM（内存溢出）的**“无锁异步持久化队列”**。当网络吞吐发生拥塞时，内存积压日志会自动落盘（采用数据隔离的日志块 + 独立索引文件架构），并外挂 CRC32 循环冗余校验保障断电恢复的数据 100% 完整无损。辅以平滑自动重连与 Token 心跳探活机制。
- **金融级链路加密与反逆向安全**：自主构建强网络安全屏障，采用最前沿的 **TLSv1.3 加密套件结合 mTLS 双向证书强校验**拦截中间人攻击（MITM）。利用 **HMAC 散列签名算法**确保连接合法性；针对敏感配置，调用 **OpenSSL (AES-256-GCM)** 结合 PBKDF2 密匙派生（10000 轮加盐哈希算法）对落地配置文件实施硬加密，彻底斩断逆向渗透通道。
- **现代化架构与工程基础设施**：建立现代化的 C++ 工程体系，重度耦合 `spdlog`（异步极速日志记录防阻塞）、`toml` 参数配置热加载，并深度借助 vcpkg / CMake 构建完善的跨平台依赖注入与并发多层编译管理。

### 💡 面试高优考点提取 (Interview Highlights)

#### 🛠️ 核心技术点 (Hard Skills)
1. **高性能 RPC / 报文协议治理**：对比 Protobuf，您深刻理解并落地了 FlatBuffers **“所见即所得 (Zero-copy deserialization)”**的强悍特性，这意味着你十分了解高频网络 I/O 场景下“避免重复内存拷贝（memcpy）”和“缓存友好性”的重要性。
2. **抗击高并发“雪崩”的容灾架构**：面对服务端降级、弱网短连接的微服务经典痛点，能够自己实现带有独立索引与 CRC32 检查的**无锁落盘队列 (Ring-buffer Spill-to-disk)**。这是高级后端架构演进中极度硬核的削峰填谷（Peak-shaving）能力体现。
3. **现代密码学机制的实战落地**：非常娴熟地运用 OpenSSL 工具链完成金融级的加密防线：双向 SSL/TLSv1.3 防嗅探、AES-GCM (带 Tag 的认证加密锁死防篡改)、上万轮的 PBKDF2 慢散列函数防彩虹表爆破，展示出了严密的 Web 安全嗅觉。

#### 💎 高价值点 (Business & Architectural Value / "所以呢？")
1. **彻底具备大型分布式系统组件开发能力**：
