**项目名称：LightLog (企业级高性能异步日志框架)** | *个人开源项目*
**核心技术：C++17 / 异步队列 / 日志轮转与归档压缩 / 多线程批处理 / 现代 CMake**
[GitHub 主页](https://github.com/hesphoros/LightLogWriteImplWithPanel)

- **高性能底层架构设计**：采用 **C++17** 标准自主研发的企业级并发日志系统。核心利用异步消息队列剥离业务线程与 I/O 线程，极大降低高并发场景下日志落地所导致的线程阻塞延迟，并支持基于吞吐量自适应的批量刷盘（Batch Processing）策略。
- **智能化生命周期管理（Rotation & Archive）**：内建支持基于文件容量、时间维度及复合阈值触发的日志**动态轮转（Log Rotation）**引擎，有效防范磁盘空间耗尽的生产级风险。同时集成多核并发归档机制，自动利用 ZIP/GZIP/LZ4 等高压缩比算法对历史日志进行异步空间回收。
- **动态过滤与多端路由流转（Sink Routing）**：自研高级规则引擎（提供基于正则表达式、触发频率限制与等级阀值的过滤），实现日志数据在一对多输出源（底层文件、可视化 Panel、外部控制台）之间的线程安全级分发与流转复用。同时无缝集成自研的高性能 `UniConv` 库实现全链路跨平台编码透明转换。
- **全现代化工程构建链路**：深度融合现代 CMake 工程哲学，提供基于 `FetchContent` / `add_subdirectory` / `find_package` 多接入规范，实现三方库（如 `nlohmann/json` 等）的零门槛自动化依赖注入。跨 Win/Linux 平台做到开箱即用的组件级分发。

### 💡 面试高优考点提取 (Interview Highlights)

#### 🛠️ 核心技术点 (Hard Skills)
1. **并发控制与消息队列**：深刻理解“生产者-消费者”模型，基于线程池（Worker Thread Pool）下发日志落盘与压缩归档任务，避免密集 I/O 卡死主线程。
2. **I/O 削峰与防灾设计**：实现内存过载状态下的防御策略设计（如 `LogQueueOverflowStrategy` 中的 `Block` 阻塞回压或 `DropOldest` 丢弃极旧策略），以此防御应用发生 OOM。
3. **设计模式与灵活性扩展**：依靠策略模式（Strategy Pattern）动态分配“轮转策略”、“压缩格式”，依靠观察者和责任链进行多目标拦截与输出（Multiple Sinks）。
4. **现代 C++ 内存管理**：在大量的异步跨线程日志内容流转中深入运用 `std::shared_ptr` 控制生命周期，使用 `std::move` 及右值引用手段全面破除对象拷贝。
