
**项目名称：UniConv (高性能并发字符编码转换库)** | *个人开源项目*
**核心技术：C++17 / SIMD 指令集 / 无锁并发 / 现代 CMake / GTest / 内存安全**
[GitHub 主页](https://github.com/hesphoros/UniConv/)

- **框架设计与架构**：基于 **C++17** 独立研发支持 180+ 种字符集的高性能转换框架。通过深度封装与重构 libiconv 引擎，完美攻克微服务与高并发架构中的字符串处理及锁竞争瓶颈。
- **极致吞吐量优化**：集成 **SIMD** 技术（AVX/NEON），并创新实现**零拷贝 I/O** 机制（结合 `std::string_view` 与内存池 `BufferLease` 分配）。单线程 UTF-8/16 转换吞吐量突破 **3.6 - 5.1 GB/s**（较原生方案提升 **4~12.5倍**），上下文获取延迟压降至 **0.75 纳秒**。
- **多线程并发治理**：核心模块采用**无锁并发描述符缓存**（4-way 并行数据结构 + O(1) LRU 逐出算法）替代传统互斥锁。针对海量短文本首创自适应多核批处理调度，在 4096 条数据的并行集测试中，吞吐量直达 **10.76 GB/s**（获得 **17.7倍** 并发加速比）。
- **工业级质量保障**：全面推行现代 C++ 规范与工程化标准，跨平台支持 Win/Linux/macOS 及 vcpkg 包管理。编写近 200 项严苛的自动化测试用例，并在 ASan (地址越界) 和 UBSan (未定义行为) 消毒器双重交叉验证下，达成 **100% 内存安全**与零故障率。

#### 🛠️ 核心技术点 (Hard Skills)
1. **现代 C++ 规范**：C++17 新特性（如 `std::string_view`）、模板元编程、RAII 资源管理。
2. **底层硬件与性能优化**：SIMD 指令集加速（AVX-512 / NEON）、CPU 缓存命中率优化、零拷贝（Zero-Copy）I/O。
3. **高并发与多线程**：无锁编程（Lock-free Programming）、细粒度并发数据结构（4-way 并行哈希）、自适应批处理并行调度（Parallel Batching）。
4. **算法与数据结构**：O(1) 时间复杂度的 LRU 缓存逐出算法。
5. **工程化与 DevOps**：现代 CMake 构建系统、vcpkg 包管理、跨平台编译（Win/Mac/Linux）、Google Test 单元测试。
6. **内存安全与诊断**：AddressSanitizer (ASan) 内存泄漏/越界检测、UndefinedBehaviorSanitizer (UBSan) 未定义行为诊断。
