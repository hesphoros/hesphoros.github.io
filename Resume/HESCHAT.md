**项目名称：HesChat (分布式集群即时通讯系统全栈实现)** | *个人全栈/架构项目*
**核心技术：C++17 / Boost.Asio / gRPC (Protobuf) / Redis & MySQL 集群 / Qt6 前端 / dlib 人脸识别**
**项目矩阵**：[Client 端](https://github.com/hesphoros/heschat) | [Gate网关](https://github.com/hesphoros/GateServer-heschat) | [Chat节点](https://github.com/hesphoros/ChatServer-heschat) | [Status全服状态节点](https://github.com/hesphoros/heschat-StatusServer)

- **微服务级分布式集群重构**：从 0 到 1 破除传统单体 IM 后端架构，独立操刀实现涵盖 `GateServer` (网关)、`ChatServer` (业务)、`StatusServer` (会话状态追踪)、`VerifyServer` (安全鉴权) 等组件的微服务拓扑网络。系统节点群内部采用 **gRPC + Protobuf** 的高密度序列化规约进行内网无缝通讯，具备极强的水平横向扩展能力。
- **高并发异步网络网关（Gateway）**：网络核心引擎深度挂载 **Boost.Asio** 异步 I/O 事件驱动基座。依靠自研 `AsioIOServicePool` 多线程轮询组及 `CSession` 模型，彻底隔离网络 I/O 开销与计算逻辑，稳健顶住海量规模客户端的密集长连接持有与高频粘包拆包吞吐洪峰。
- **全域状态流转与双级数据引擎**：针对海量社交用户场景中的高频状态切换痛点，通过 **Redis 连接池（`RedisConPool`）** 实现对海量分布式 session 在线状态的极速内存缓存；并通过封装原生的 **MySQL 动态连接池（`MysqlDao`）** 保障所有即时文字流/账号信息的防并发死锁与平滑持久化入库管理。
- **自适应跨平台前端与纯自研技术生态闭环**：不仅在多服务端表现亮眼，在展示端利用 **Qt6** 独立搭建现代化界面的跨平台桌面级通讯客户端。不仅突破性地融合 **OpenCV + dlib** 算法库作为客户端生物安全防线（人脸检测与验证识别登录），更强悍的是**在底层日构建系统中全量集成了此前自研的 [LightLog] 及 [UniConv] 底层基建组件**，形成了惊人的个人开源技术全链路生态闭环。
