# NNHDC (Neural Network Handwritten Digit Classifier) — 从零构建的 C 语言卷积神经网络

**定位：** 纯 C 语言硬核机器学习引擎，展现极深的算法底层理解与数学推导能力（高二独立完成）。

### 💡 核心亮点 / Elevator Pitch
*“在绝大多数学生还没听说过微积分的高二阶段，该候选人拒绝使用 PyTorch/TensorFlow 这类高级 API，而是直接用**纯 C 语言、通过二维数组和指针，从零硬编码实现了卷积神经网络（CNN）的完整前向传播、反向传播与链式求导**。这种剥离所有高层封装、直击数学与内存底层的 Geek 精神，展现了对深度学习计算过程的顶级洞察力与骇客级的代码掌控力，是做底层 AI 编译器、张量计算库加速的极佳好苗子。”*

---

### 📝 简历可用描述 (Resume Bullet Points)

**项目名称：** C-Core CNN Engine (NNHDC)
**角色：** 独立开发者 / 算法底层研发
**技术栈：** Pure C / 卷积神经网络 (CNN) / Matrix Calculus / Backpropagation / Gradient Descent

- **从零实现纯 C 深度学习引擎：** 摒弃第三方框架（TensorFlow/PyTorch/BLAS），基于纯 C 语言从零实现卷积神经网络架构，包含 `Conv2d` (卷积层)、`MaxPool2d` (池化层) 及 `Flatten` 展平机制，直接对底层内存和多维数组进行手写控制，成功在本地完成手写数字 MNIST 数据集的训练与推断。
- **手写前向/反向传播算法：** 独立推导并代码化深度学习计算图中的偏导数矩阵链式法则，实现了卷积层的误差反向传播、权重参数梯度计算与更新同步。对交叉熵损失函数（Cross-Entropy Loss）与 Softmax 激活函数进行底层硬编码，实现了高维特征的降维计算。
- **内存安全与计算解耦：** 在缺乏高级语言垃圾回收机制的约束下，使用原生 C 指针和动态内存规划处理大量高维数组（如 `28x28` 的图像矩阵卷积），规避内存泄漏与指针越界；手工实现随机梯度下降（SGD），证明了对算法黑盒最深层的理解力。

- **当被问及“为什么不用 PyTorch 而是用纯 C 写”：**
  *“高二那年我对神经网络底层究竟发生了什么充满好奇。调 API 就像一个黑盒，于是我决定自己造轮子。最大的挑战是不使用自动求导机制，自己推导二维卷积和池化的反向传播（Backprop）梯度矩阵，并在没有 BLAS 的情况下纯用迭代手写实现。虽然它比不上现代框架快，但让我彻底顿悟了张量运算、步长（Stride）和内存空间排布的关系，这也是我现在写系统级项目如此顺手的原因。”*

- **硬核能力暗示 (Hardcore Flex)：**
  大多数只会“调参”的算法工程师并不清楚一维连续内存在做卷积时的 Cache Miss 问题，候选人可以通过这个项目，轻松将话题引导向“C/C++ 内存布局排列对矩阵乘法性能的影响”、“为什么现在的高级 AI 计算框架需要做内存连续化优化”等宏大议题上。
