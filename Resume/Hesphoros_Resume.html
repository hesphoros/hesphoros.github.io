UniConv —— 高性能字符编码转换库
++ C++17 / AVX-512 SIMD / Lock-free / Zero-copy
  • SIMD 加速与极限扩展： 动态集成 simdutf，借助 AVX-512/NEON 指令集将单核字符转换速度提升 4~12.5 倍（最高达 12 GB/s）；同时实现多核批处理架构，吞吐量相较原生提速 17.7 倍至 10.76 GB/s。
  • 高并发无锁与零拷贝： 核心缓存层剥离常规锁机制，采用 4-Way 伪分片哈希表加 O(1) LRU 淘汰策略。实现 string_view 与 BufferLease 结构的 Zero-copy（零拷贝）透传，极限压榨 CPU 计算红利。
LuspSearchCore / MyTFS —— 底层检索与分布式文件引擎
++ NTFS MFT ByPass / Trigram Index / mmap Zero-copy
  • 全盘秒级高优检索引擎 (LuspSearch)： 直接解析底层 NTFS $MFT 表结合 USN 日志追踪，实现全盘千万级数据极速并发索引。结合 Trigram 倒排算法，单硬盘千万级文件重建索引最快仅需数分钟，正则/模糊搜查达到毫秒（ms）级响应；具备后台资源温控机制，实现极低空载占用（CPU < 1%）与高缓存命中，该工程设计已被应用于商用软件。
  • 自研文件引擎 (MyTFS)： 基于 C++11 实现海量小文件的存储归档，配合 mmap 的零拷贝（Zero-copy）机制与内存映射回收消除传统 read/write 所带来的模式切换和缓存开销。
LightLog —— 高性能异步并发日志组件
