**字符串字面量（string literal）**，简单说就是：

> **直接写在 C/C++ 源代码里的字符串。**

比如：

```
const char* str = "Hello";
```

这里的：

```
"Hello"
```

就是**字符串字面量**。

---

### 1. 为什么叫“字面量”？

因为它是你**直接写出来的值**。

比如：

```
int a = 123;
```

`123` 是**整数字面量**。

```
double pi = 3.14;
```

`3.14` 是**浮点数字面量**。

```
char c = 'A';
```

`'A'` 是**字符字面量**。

```
const char* s = "Hello";
```

`"Hello"` 就是**字符串字面量**。

所以：

```
123       → 整数字面量
3.14      → 浮点字面量
'A'       → 字符字面量
"Hello"   → 字符串字面量
```

---

### 2. C++ 中常见的字符串字面量

你以后做 UniConv 会经常碰到这些：

```
"Hello"
L"你好"
u8"你好"
u"你好"
U"你好"
```

它们分别对应不同的字符类型：

|写法|类型|常见编码/用途|
|---|---|---|
|`"你好"`|`const char[]`|执行字符集|
|`L"你好"`|`const wchar_t[]`|宽字符串|
|`u8"你好"`|`const char8_t[]`（C++20）|UTF-8|
|`u"你好"`|`const char16_t[]`|UTF-16|
|`U"你好"`|`const char32_t[]`|UTF-32|

例如：

```
auto a = "你好";
auto b = L"你好";
auto c = u8"你好";
auto d = u"你好";
auto e = U"你好";
```

它们**看起来都是“你好”**，但实际上类型和底层表示可能完全不同。

---

### 3. 这和你刚才问的“执行字符集”直接相关

最重要的是这个：

```
const char* str = "你好";
```

`"你好"` 是**普通字符串字面量**。

它里面的 `"你好"` 到底变成什么字节，和**执行字符集**有关。

例如可能最终是：

```
UTF-8:
E4 BD A0 E5 A5 BD
```

也可能是：

```
GBK:
C4 E3 BA C3
```

而：

```
const char8_t* str = u8"你好";
```

则明确表示这是 **UTF-8 字符串字面量**。

所以从 UniConv 的角度来看，可以简单理解成：

```
"你好"
  ↓
普通字符串字面量
  ↓
受执行字符集影响


u8"你好"
  ↓
UTF-8 字符串字面量
  ↓
明确要求 UTF-8
```
