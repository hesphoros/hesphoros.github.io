[[4. 对象池]]书接上文

`StackFactory::get()`把原始指针this保存到了`lamada`中,如果`StockFactroy`的生命周期比Stock短,那么Stock的析构会回调使用`this->m_mutex` 和 `this->m_stocks`访问野内存. 

我们可以使用`shared_ptr`大法来解决对象的生命周期问题,但是`StackFactory::get`本事是个成员函数,如何获得一个指向当前对象的`shared_ptr<StockFactory>`对象呢?

这个办法就是`enable_shared_from_this` . 这是一个以其派生类作为模板类型实参的基类模板,继承它,this指针就能变为shared_ptr

```cpp

class StockFactory4 : public  std::enable_shared_from_this<StockFactory4>,
                      private NoCopyAble{...}
```

为了使用`shared_from_this()`,`StockFactory` 不能是stack object,必须是 heap object
