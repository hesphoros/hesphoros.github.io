# 尾随返回类型

在 C++11 之前，函数的返回类型通常在函数名之前指定。然而，在某些情况下，表达复杂的返回类型可能具有挑战性，尤其是在处理模板函数或带有 decltype 声明的函数时。

使用尾随返回类型语法，您可以在参数列表之后使用 `auto` 关键字和尾随的 `->` 箭头来指定函数的返回类型。这样，您就可以使用表达式和 `decltype` 来根据函数的实现推断返回类型。

在旧格式中，必须在函数名称之前指定返回类型。

**C++11之前的返回类型语法***

```c
function_return_type function_name(parameter_list){   
     // 函数实现  
    // ...   
}  
```

**在新语法中，auto 关键字写在函数名之前，返回类型在函数名和参数列表之后指定。****

## ***尾随返回类型的语法***

```c
auto function_name(parameter_list) -> return_type {   
    // 函数实现  
    // ...   
}  
```

## ***尾随返回类型****示例

```c++
// C++ Program to illustrate Trailing Return Type in C++ 11
#include <iostream>

// Trailing return type using auto and decltype
auto add(int a, int b) -> decltype(a + b) { return a + b; }

int main()
{
    int x = 5, y = 10;
    auto result = add(x, y);
    cout << "Result: " << result
              << endl; // Output: Result: 15
    return 0;
}
```
