

## 一、最推荐的教材

### 🥇 1. 《C++ Templates: The Complete Guide》

作者：David Vandevoorde、Nicolai Josuttis、Douglas Gregor

这是我最推荐你作为**主教材**的一本。

官方介绍也把它定位为系统讲解现代 C++ Template 的参考书，第二版覆盖 C++11/14/17，并且专门深入讲了标准库 `type_traits`。([Josuttis](https://www.josuttis.com/tmplbook/tmplbook.html?utm_source=chatgpt.com "C++ Templates"))

重点不是从头到尾死磕，而是重点看：

```text
Template Basics
    ↓
Template Argument Deduction
    ↓
Specialization
    ↓
Variadic Templates
    ↓
Compile-Time Programming
    ↓
Type Traits
    ↓
SFINAE
    ↓
Metaprogramming
```

尤其值得你现在看的内容：

```cpp
template<typename T>
struct traits;

template<typename R, typename C, typename... Args>
struct traits<R (C::*)(Args...)>
{
    using return_type = R;
    using class_type = C;
    using args_type = std::tuple<Args...>;
};
```

你前面正在研究的这种代码，本质上就是这本书里的核心思想：

> **Partial Specialization + Type Pattern Matching**

---

### 🥈 2. 《Modern C++ Design》

作者：Andrei Alexandrescu

这本非常适合你这种**想自己做高性能 C++ 库 / 编译期反射框架**的人。

它比较老，出版于 2001 年，主要基于 C++98，但它的很多思想直到今天依然非常重要。([维基百科](https://en.wikipedia.org/wiki/Modern_C%2B%2B_Design?utm_source=chatgpt.com "Modern C++ Design"))

重点不是学习里面的旧语法，而是学习：

```text
TypeList
Policy-Based Design
Type Traits
Compile-Time Selection
Generic Programming
Template Techniques
```

例如：

```cpp
template<class T>
struct TypeTraits
{
    using value_type = T;
};
```

进一步发展：

```cpp
template<class T>
struct TypeTraits;

template<>
struct TypeTraits<int>
{
    static constexpr bool is_integer = true;
};
```

再进一步：

```cpp
template<class T>
struct TypeTraits
{
    static constexpr bool is_pointer = false;
};

template<class T>
struct TypeTraits<T*>
{
    static constexpr bool is_pointer = true;
};
```

这就是你现在学习的东西的祖先之一。

**建议你不要把 Modern C++ Design 当第一本书。**

它更像：

> **第二阶段的“内功心法”。**

### 🥉 3. 《C++ Template Metaprogramming》

作者：David Abrahams、Aleksey Gurtovoy

这一本更加纯粹地讨论 TMP。

Modern C++ 社区的资料也把它列为 advanced template metaprogramming 经典教材。([现代 C++](https://www.modernescpp.org/resources/?utm_source=chatgpt.com "Resources – MC++ MENTORING"))

但是：

**不建议你现在直接啃。**

因为它很多内容建立在比较传统的 TMP 思维之上：

```text
type → type
type → value
type → type sequence
compile-time algorithm
metafunction
metafunction class
```

如果你现在还在刚理解：

```cpp
typename
template<>
partial specialization
decltype
std::void_t
std::enable_if
```

直接上这本很容易：

> “每个字我都认识，但是这一页到底在干什么？”

# 四、你现在最应该学什么？

结合你最近问我的：

- `type_traits`
  
- `SFINAE`
  
- `constexpr`
  
- 成员函数指针 traits
  
- 编译期反射
  
- 高性能编译期反射库
  

我建议你**暂时不要急着看大型 TMP 框架源码**。

先把下面这些东西彻底吃透：

### Level 1：模板机制

```cpp
template<typename T>
void foo(T);

template<typename T>
struct Foo;
```

理解：

```text
template parameter
template argument
deduction
instantiation
specialization
partial specialization
```

---

### Level 2：类型系统

重点：

```cpp
decltype
std::declval
std::is_same
std::is_base_of
std::is_pointer
std::is_member_function_pointer
std::remove_cv
std::remove_reference
std::decay
std::conditional
```

然后自己实现：

```cpp
template<typename T>
struct remove_reference;
```

---

### Level 3：SFINAE

重点理解：

```cpp
std::enable_if
std::void_t
decltype
std::declval
```

例如：

```cpp
template<typename T, typename = void>
struct has_size : std::false_type {};

template<typename T>
struct has_size<T, std::void_t<
    decltype(std::declval<T>().size())
>> : std::true_type {};
```

你需要真正理解：

> **为什么 substitution failure 没有变成 compilation error？**

而不是只记：

> `void_t` 可以检测成员。

---

# 五、然后进入真正的 TMP

这时候开始玩：

### TypeList

```cpp
template<typename... Ts>
struct TypeList {};
```

然后实现：

```cpp
TypeList<int, float, double>
```

再实现：

```cpp
TypeListSize
TypeAt
PushFront
PushBack
Contains
IndexOf
Transform
Filter
```

例如：

```cpp
using T = TypeList<int, float, double>;

static_assert(TypeListSize<T>::value == 3);
```

这一阶段非常重要。

因为你会开始意识到：

> **TMP 本质上就是在编译期操作“类型数据结构”。**

---

# 六、然后你就可以开始做你自己的“编译期反射”

这时候就会和你现在的项目直接接上。

例如：

```cpp
template<auto Ptr>
struct member_traits;
```

然后：

```cpp
template<typename R, typename C, typename... Args,
         R (C::*Ptr)(Args...)>
struct member_traits<Ptr>
{
    using return_type = R;
    using class_type = C;
    using args_type = TypeList<Args...>;
};
```

进一步：

```cpp
template<auto Ptr>
using member_class_t =
    typename member_traits<Ptr>::class_type;
```

最后发展成：

```cpp
reflect<MyClass>()
```

得到：

```text
Class
 ├── Name
 ├── Base Classes
 ├── Members
 │    ├── Name
 │    ├── Type
 │    ├── Pointer
 │    └── Attributes
 │
 └── Functions
      ├── Name
      ├── Return Type
      ├── Arguments
      └── Pointer
```

这就已经进入你想做的**编译期反射**领域了。

## 最后给你一个非常明确的建议

**如果你现在就开始：**

```text
① C++ Templates 2nd
       ↓
② type_traits
       ↓
③ SFINAE
       ↓
④ Variadic Templates
       ↓
⑤ constexpr
       ↓
⑥ TypeList
       ↓
⑦ Compile-time Algorithms
       ↓
⑧ Concepts
       ↓
⑨ Modern C++ TMP
       ↓
⑩ 阅读 Boost / STL
       ↓
⑪ 自己实现 Compile-time Reflection
```

而且**不要把目标设成“学会模板元编程”**。

以你现在正在做的编译期反射项目为目标，会更有效：

> **每学一个 TMP 技术，就想办法把它用到你的 Reflection Library 里。**

例如学 `partial specialization` → 实现 `member_traits`；  
学 `type_traits` → 实现类型系统；  
学 `SFINAE` → 实现成员检测；  
学 `variadic template` → 实现参数列表；  
学 `TypeList` → 实现反射成员集合；  
学 `constexpr` → 实现编译期元数据；  
学 `Concepts` → 给反射 API 做约束。

这样学的速度会比单纯刷教材快很多。
